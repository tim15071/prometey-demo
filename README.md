# Прометей · демонстрационная версия

Публичная сборка сайта СНТ «Прометей» для просмотра и согласования.
Файлы исходного проекта и локальный исследовательский архив сюда не входят.
Раздел «Камеры» поддерживает HLS-трансляции и отдельную HTTPS-страницу защищённого просмотра после подключения видеосервера. Постоянный источник не подключён. Пароли камер и облачные ID в публичное хранилище не добавляются.
Демонстрация работает как статический сайт. Собственная PHP-админка для всех девяти разделов подготовлена для SpaceWeb: https://tsnprometey.ru/?page=manage. Для активации нужен настроенный HTTPS и отдельный пароль владельца сайта. Репозиторий не является рабочим хранилищем этой админки.
Конфигурация локальных форм: .pages.yml. Снимок материалов демонстрации: content/*.json и uploads/.
После первой миграции обновление дизайна на основном сайте должно сохранять его рабочие content/ и uploads/. Получите резервную копию с хостинга перед выпуском; не заменяйте её снимком демонстрации.
